# Temporary OpenTelemetry security override

The owner-authorized exception for [CVE-2026-118259](https://github.com/open-telemetry/opentelemetry-java/security/advisories/GHSA-ccrj-gw8r-854m) replaces the existing 14 `io.opentelemetry` core artifacts in Keycloak 26.8.1 with official 1.67.0 artifacts (API incubator: 1.67.0-alpha). Quarkus 3.40.1 and the existing instrumentation artifacts remain unchanged. This is a dependency repair, with no vulnerability ignore or weakened gate. Published status and exact digests belong in the [security history](security/history.md); a source override does not repair existing images.

An API/context/common-only upgrade failed the real SDK compatibility probe: SDK 1.62.0 references the removed API-internal `ConfigUtil` class. The reviewed alternative keeps the existing core artifact inventory and aligns API, common, context, SDK, auto-configuration SPI and exporters to the same official release. No additional sender/provider is introduced: Quarkus retains its existing transport integration. The local dependency probe passed with the aligned cohort; actual Keycloak compatibility requires native runner validation.

`dependencies/keycloak/opentelemetry.lock.json` pins the selected Keycloak version, all original Maven payload hashes and all replacement hashes. Original and replacement artifacts were checked against Maven Central's published SHA-256 checksums. `scripts/opentelemetry-dependencies.mjs` constructs fixed Maven URLs, validates safe/coherent identity and checks cache/download bytes. All original distribution hashes are checked before replacement. Existing filenames are retained because Quarkus' resolved application model names them; embedded version metadata and actual payloads become 1.67.0. No JAR is rebuilt or edited.

Before optimization, the build probe checks actual API/context/common metadata, the aligned SDK, normal W3C trace/baggage propagation, in-memory span export, metrics/log linkage and bounded malformed-header parsing. The builder also exercises tracing-enabled Quarkus augmentation, then explicitly builds both final profiles with tracing disabled. Final rootfs validation checks every locked payload and rejects duplicate module JARs. Native runtime checks cover the existing PostgreSQL/TLS/authentication/shutdown and AWS offline transport contracts. These checks are not a live tracing-collector or RDS/PolarDB certification.

CI and publication scans additionally require the entire fixed cohort's metadata and absence of CVE-2026-118259, even though the general gate only blocks fixable HIGH/CRITICAL findings. No other CVE is suppressed. The publication assertion applies to a plan declaring this CVE repair.

Retirement is mandatory on the next Keycloak dependency change: the exact Keycloak version or original-payload drift fails closed. Inspect the selected upstream OpenTelemetry inventory and official fix, remove the override when upstream supplies fixed coherent dependencies, and retain the parsing/SDK regression. If upstream still requires an exception, review and pin the new source graph through an Issue/PR. Preserve original security records and append publication/correction facts rather than relabeling old tags as repaired.
